# 📹 Clone da Home Page do YouTube

Uma recriação da interface inicial (Home Page) do YouTube, focada em praticidade, design responsivo e reprodução fiel dos componentes visuais da plataforma.

---

## 🚀 Funcionalidades

- **Header / Barra de Navegação:**
  - Logo do YouTube
  - Barra de pesquisa com botão de busca e ícone de microfone
  - Ícones de ações (criar vídeo, notificações, perfil)
- **Menu Lateral (Sidebar):**
  - Navegação entre as seções (Início, Shorts, Inscrições, Você, etc.)
- **Grid de Vídeos:**
  - Exibição de thumbnails com tempo de duração do vídeo
  - Foto de perfil do canal, título do vídeo e nome do canal
  - Contagem de visualizações e tempo de publicação
- **Design Responsivo:**
  - Layout adaptável para telas de computadores, tablets e dispositivos móveis

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página
- **CSS3:** Estilização, layout em Grid / Flexbox e responsividade
- **JavaScript:** [Se aplicável] Interatividade (como alternar menu lateral, busca, etc.)
- **Ícones:** Font Awesome / Lucide Icons / SVG Inline

---

Para rodar este projeto localmente, você precisa apenas de um navegador web atualizado (Google Chrome, Firefox, Edge, etc.).
